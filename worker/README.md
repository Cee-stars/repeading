# 同期の置き場（Cloudflare Workers + KV）

端末をまたいで教材と調べた単語を同期するための、置き場だけを担う小さなプログラム。
本体（`sync-worker.js`）は 100 行ほどで、やることは「鍵ごとに JSON を 1 つ預かる」だけ。

無料枠に十分収まる。このアプリの使い方なら、1 日の読み書きは数十回程度。

## 置き方

Cloudflare のアカウントが要る（無料）。

```bash
cd worker
npx wrangler login

# 中身を置く棚を作る。出力された id を wrangler.toml に貼る。
npx wrangler kv namespace create SYNC

npx wrangler deploy
```

最後に出る `https://repeading-sync.<あなた>.workers.dev` が置き場の URL。
アプリの「同期」欄にこれを貼る。

ダッシュボードから手で作ってもよい。その場合は Workers で新規作成して
`sync-worker.js` の中身を貼り、KV 名前空間を作って **変数名 `SYNC`** で結びつける。

## 仕組み

| | |
| --- | --- |
| `GET /` | 預けてある中身と版を返す。無ければ `{payload: null, rev: null}` |
| `PUT /` | `{payload, ifRev}` を受け取って保存し、新しい版を返す |

どちらも `Authorization: Bearer <鍵>` が要る。

**鍵を知っていることが、そのまま読み書きの権利になる。** 登録も利用者の概念も持たない。
鍵は端末側で 26 文字の乱数として作られるので、総当たりは現実的でない。

**鍵そのものは保存しない。** SHA-256 を取った値を棚の名前に使う。
KV の中身が漏れても、そこから鍵は復元できない。

**書き込みは版（rev）で守る。** 手元が知っている版と食い違えば 409 を返し、
そのとき置き場にある中身も一緒に返す。端末はそれと突き合わせてから出し直す。
これが無いと、2 台が同時に書いたときに片方の変更が黙って消える。

## 気をつける点

- **KV は書いた直後の読み出しが古いことがある**（世界中に配るまで最大 1 分ほど）。
  2 台を続けざまに操作すると、片方が一瞬古い中身を見る可能性がある。
  版の仕組みがあるので変更が消えることはないが、反映が一拍遅れることはある。
- `ALLOWED_ORIGIN` を設定すると、自分のサイトからだけに絞れる。
  絞らなくても鍵が要ることは変わらないが、絞っておくほうがよい。
- 置き場を畳めば同期は止まる。中身は各端末のブラウザに残るので、練習は続けられる。

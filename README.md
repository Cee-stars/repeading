# Repeading

YouTube の字幕を一文ずつ区切って、「聞く → 真似る」を繰り返すリピーティング練習アプリ。
録音も発音採点もしない。**区切る・止まる・待つ**だけに集中したツール。

設計の詳細と今後の計画は [PLAN.md](./PLAN.md) を参照。

## 使い方

```bash
npm install
npm run dev
```

1. **動画の URL** を貼る（`youtu.be` / `shorts` / 動画 ID の直接入力も可）
2. **字幕** を貼るか、SRT / VTT ファイルをドロップする
   - YouTube 側での取り方: 動画下の `…`（その他）→ **文字起こしを表示** → 右の transcript パネルを選択してコピー
3. 教材名を付けて **練習を始める** を押す

形式（SRT / WebVTT / 文字起こしの貼り付け）は自動で判定される。
取り込むと自動で文に分割され、最初の 5 文がプレビューされる。

取り込んだ教材はブラウザに保存され、次からはトップの一覧から開くだけで続きから始まる。
字幕を貼り直す必要はない。

## 練習画面

一文だけ再生されて自動で止まり、「真似る」ための無音が入り、次の文へ進む。

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 停止。無音待ち中は待たずに次へ |
| `←` `→` | 前の文 / 次の文 |
| `R` `↑` | 今の文をもう一度 |
| `M` | 今の文に苦手マークを付け外し |
| `H` | 字幕表示を切り替え（隠す → ヒント → 表示） |
| `S` | 再生速度（0.5× → 0.75× → 1×） |
| `Esc` | 停止 |

調整できる設定:

- **速度** 0.5× / 0.75× / 1×
- **繰り返し** 次の文へ進む前に同じ文を何回再生するか（1〜3 回）
- **真似る間** 無音の長さ（文の長さの 0〜2 倍）
- **字幕** 隠す / ヒント（各単語の 1 文字目だけ）/ 表示
- **自動で次の文へ** オフにすると自分のペースで進められる
- **苦手な文だけ** ★ を付けた文だけを流す復習モード

## 文の手直し

自動分割は字幕の質に依存するので、外れることがある。聞いている最中に直せる。

右上の **文を編集** を押すと、いま聞いている文に対して操作できる。

- **分割** 語と語の間を押すと、そこで 2 つの文に分かれる
- **前の文とつなぐ** 切れすぎた文を 1 つに戻す
- **区間の微調整** 開始・終了を 0.2 秒ずつ動かす。頭が切れる / 次の文を巻き込む場合に
- **試聴** 直した区間をその場で聞き直す

苦手マークと再開位置は文の id で持っているので、編集しても印と現在位置は飛ばない。

## 保存されるもの

- **教材**（動画 ID・教材名・文リスト・苦手マーク・再開位置）→ IndexedDB
- **練習設定と配色** → localStorage

いずれもブラウザの中だけに残り、外に送られることはない。一覧から教材を削除できる。
プライベートモードなど保存領域が使えない環境では、保存だけが無効になり練習は普通にできる。

## 見た目

Apple のサイトや iOS の UI に寄せたデザイン言語で組んである。
OS のフォント（`-apple-system` 系）、ピル型のアクションボタン、iOS 風のセグメンテッドコントロールと
スイッチ、角丸 18px のカードと控えめな影。Apple のロゴやフォントファイルなどの素材は含まない。

配色はライトが既定（背景 `#f5f5f7`）。OS がダークならダークで開き、以後も OS の切り替えに追従する。
右上のトグルで手動切り替えもでき、その場合は選択が `localStorage` に保存されて追従をやめる。
ダーク側も純黒は使わず `#1d1d1f` を基調にしている。

## 公開

GitHub Pages への配信は `.github/workflows/pages.yml` が行う。ブランチに push すると
テストとビルドを通し、その成果物 (`dist`) を Pages に渡す。

**Pages の Source は「GitHub Actions」にする。**「Deploy from a branch」にすると
リポジトリのルート（ビルド前のソース）がそのまま配信され、`index.html` が
`/src/main.tsx` を読もうとして動かない。

`vite.config.ts` の `base` は `'./'` なので、`https://<user>.github.io/<repo>/` のような
サブパス配信でもアセットの参照は崩れない。

## 開発

```bash
npm run dev      # 開発サーバー
npm test         # テスト（パーサと文分割エンジン）
npm run build    # 本番ビルド
```

```
src/
  lib/
    parseSubtitles.ts    形式を自動判定して cue に正規化
    segment.ts           重複除去と文への結合（分割精度の肝）
    useYouTubePlayer.ts  IFrame Player API での区間再生
    usePractice.ts       聞く / 真似る の状態機械
    material.ts          教材の型と純粋な操作（再開位置・苦手マーク・復習の絞り込み）
    edit.ts              文の分割・結合・区間のずらし
    db.ts                IndexedDB の薄いラッパ
    useLibrary.ts        保存した教材の読み書き
    useSettings.ts       練習設定の永続化
    useTheme.ts          配色の切り替えと OS 設定への追従
  components/
    ImportPanel.tsx      取り込み画面
    Library.tsx          保存した教材の一覧
    PracticeView.tsx     練習画面
    SentenceList.tsx     文の一覧
    ThemeToggle.tsx      配色トグル
```

字幕は自分で用意したものを取り込む形にしている。理由と自動取得の選択肢は
[PLAN.md](./PLAN.md#字幕の入手方法をなぜ貼り付けにしたか) にまとめた。

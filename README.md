# Repeading

YouTube の字幕を一文ずつ区切って、「聞く → 理解する → 真似る」を繰り返すリピーティング練習アプリ。
録音も発音採点もしない。**区切る・止まる・待つ**だけに集中したツール。

設計の詳細と今後の計画は [PLAN.md](./PLAN.md) を参照。

## 使い方

```bash
npm install
npm run dev
```

1. **動画の URL** を貼る（`youtu.be` / `shorts` / 動画 ID の直接入力も可）
2. **字幕** を貼るか、SRT / VTT ファイルをドロップする
   - YouTube 側での取り方: 動画下の `…`（その他）→ **文字起こしを表示** → 右の transcript パネルを選択してコピー
3. 教材名を付けて **練習を始める** を押す

形式（SRT / WebVTT / 文字起こしの貼り付け）は自動で判定される。
取り込むと自動で文に分割され、最初の 5 文がプレビューされる。

## 自分のレベルに合うか見る

動画を外から見て難易度を当てるのは難しい。でも**字幕を貼った時点で材料は揃っている**ので、
「練習を始める」を押す前に手応えが出る。

| | 意味 |
| --- | --- |
| **話す速さ** | 1 分あたりの語数。リピーディングではこれが一番効く |
| **1 文の長さ** | 真似るときに覚えておく語数 |
| **読みやすさ** | 語と文の長さから出す 0〜100 の目安。高いほどやさしい |

速さは**実際に喋っている時間**で割る（無音は除く）。間を含めると、ゆっくり喋る人と
間が多いだけの人の区別が付かなくなる。

判定は 5 段階で、速さを重く見る（速さ 65 : 文章の硬さ 35）。真似られるかは、
まず付いていけるかで決まるため。

合わないときの逃げ道も一緒に出る。速すぎるなら **0.75×** にすれば換算で何語/分になるかを
示すし、1 文が長いなら **文を編集**で切れる。つまり**少し速い動画でも使える**。

保存した教材の一覧にも速さが並ぶので、続けていくと「自分はこのあたりなら回せる」が
見えてくる。外の基準より、自分の記録の方が当てになる。

> 目安はすべて字幕から機械的に出した推定で、辞書も外部サービスも使っていない。
> 音節は母音のかたまりを数える近似なので、語によっては外れる。

取り込んだ教材はブラウザに保存され、「練習を始める」の下の **保存した教材** に並ぶ。
押せば続きから始まるので、別の動画に移っても前のものは残る。字幕を貼り直す必要はない。
教材名は自由に付けられるので、テーマ別に整理したいときはそこで分ける。

## 練習画面

一文だけ再生されて自動で止まり、**意味を取るための間**が入り、続けて**真似るための無音**が入り、次の文へ進む。

理解を挟まずに真似ると、音をなぞるだけで意味が入らない。だから理解は設定ではなく、
ループの中の 1 段として置いてある。この段のあいだは、字幕の設定にかかわらず全文が出る。
意味を取るための段なので、ここで隠していては何も起きない。語句を調べるのもこの段。

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 停止。理解の間は「真似る」へ、無音待ち中は待たずに次へ |
| `←` `→` | 前の文 / 次の文 |
| `R` `↑` | 今の文をもう一度 |
| `M` | 今の文に苦手マークを付け外し |
| `H` | 字幕表示を切り替え（隠す → ヒント → 表示） |
| `S` | 再生速度（0.5× → 0.75× → 1×） |
| `Esc` | 停止 |

調整できる設定:

- **速度** 0.5× / 0.75× / 1×
- **繰り返し** 次の文へ進む前に同じ文を何回再生するか（1〜3 回）
- **理解する間** 意味を取るための間（文の長さの 0〜2 倍）。「なし」にすればこの段を飛ばす
- **真似る間** 無音の長さ（文の長さの 0〜2 倍）
- **字幕** 隠す / ヒント（各単語の 1 文字目だけ）/ 表示
- **自動で次の文へ** オフにすると自分のペースで進められる
- **苦手な文だけ** ★ を付けた文だけを流す復習モード

## 文の手直し

自動分割は字幕の質に依存するので、外れることがある。聞いている最中に直せる。

右上の **文を編集** を押すと、いま聞いている文に対して操作できる。

- **分割** 語と語の間を押すと、そこで 2 つの文に分かれる
- **前の文とつなぐ** 切れすぎた文を 1 つに戻す
- **区間の微調整** 開始・終了を 0.2 秒ずつ動かす。頭が切れる / 次の文を巻き込む場合に
- **試聴** 直した区間をその場で聞き直す

苦手マークと再開位置は文の id で持っているので、編集しても印と現在位置は飛ばない。

## 単語を調べる

字幕を **表示** にしているときだけ、字幕の語句を選んで調べられる。

- **単語を押す** → その語が選ばれる
- **なぞる** → 複数語をまとめて選ぶ（`put up with` のような固まり用）
- キーボードだけの場合は、語に Tab で移動して `Enter`（1 語のみ）

選ぶと行き先が 3 つ出る。どれも外部サイトへのリンクで、API キーもサーバーも要らない。

| | 出るもの | 向いているもの |
| --- | --- | --- |
| **意味** | 英和辞典 | 単語と、辞書に載っている熟語 |
| **例文** | 例文検索 | 辞書に項目が無い組み合わせ。実際にどう使われるか |
| **訳** | 翻訳 | どの辞書にも無い言い回し（2 語以上のときだけ出る） |
| **AI に聞く** | 質問文をコピー | 文法が絡むとき。Claude などに貼る |

**単語単位の辞書が一番役に立たないのは、知らない単語が入っていないフレーズ。**
`put up with` は構成する語がどれも簡単なのに、一つずつ引いても意味にたどり着かない。
そういう固まりに対して欲しいのは語義ではなく「どう使われるか」なので、例文を常に並べている。

### AI に聞く（アプリは API を呼ばない）

**AI に聞く** を押すと、その語句と出てきた文を含む質問文がクリップボードに入る。
Claude などに貼れば、意味・文法・似た表現との使い分けが返ってくる。

アプリから直接 API を呼ばないのは、**鍵の置き場所が無いから**。このアプリはサーバーを
持たず、ブラウザだけで動く。API キーをそこに書くと、ページを開いた誰もが読めてしまう
（開発者ツールに出る）。キーを預かるサーバーを立てれば防げるが、今度はサーバー代がかかり、
「費用ゼロ・サーバーゼロ」で成り立っている作りが崩れる。

**呼ぶのをアプリではなく利用者にすれば、どちらの問題も消える。** 利用者がすでに契約して
いるものを使うので、追加の費用もかからない。

文末の記号は除いて引き、`don't` のアポストロフィは語の一部として残す。数字は引かない。
引き先を変えたい場合は `src/lib/dictionary.ts` の URL を差し替える。

### 調べた単語

調べた語句は、その場で **調べた単語** に記録される。覚える操作は要らない。
フレーズも 1 件として残る（`put up with` が 3 回、のように出る）。
一覧は「保存した教材」の下にあり、押せばまた辞書が開く。

- 同じ語句を何度引いても行は増えず、**回数**が増える。覚えられていないものがそれで分かる
- 単語と一緒に、**出てきた文**と**どの教材か**を残す。単語だけより思い出しやすい
- 並びは **新しい順** と **よく調べた順** を切り替えられる
- 一度調べた単語は、字幕の中でも下線が付く。同じ単語で何度も止まっているかが見える
  （印が付くのは 1 語で調べたものだけ。フレーズは一覧に残る）
- 一覧から開き直した分は回数に数えない。見直しで数が膨らむと当てにならなくなるため
- **まとめて AI に聞く** で、調べた語句すべてを 1 つの質問文にしてコピーできる。
  何度も調べた語には回数が付くので、どれが身に付いていないかも一緒に伝わる
  （一度に入るのは 40 件まで。並び替えた上から順に入る）

辞書の語義そのものは取り込めない（引き先のコンテンツなので、取得するには別途サーバーも要る）。
残るのは「いつ・どの文で・何回調べたか」であって、単語帳の訳語欄ではない。

**文法は辞書では解決しない。** 分からない文は `M` で苦手マークを付けておき、
あとでまとめて調べるか、誰かに聞くのが早い。

## iPhone で使う

指で操作できるようにしてある。タップ対象は 44px 以上、キーボードの近道一覧は出さず、
案内も「再生を押して開始」に変わる。

**ホーム画面に追加**すると、Safari の UI が消えて全画面のアプリとして開く。
共有ボタン → ホーム画面に追加。

字幕は YouTube 側からコピーする必要があるが、iPhone の YouTube アプリは
文字起こしのコピーがしにくい。最初は PC で取り込んでおくのが楽（教材はブラウザごとに
保存されるので、PC で取り込んだものは PC 側にだけ残る点に注意）。

iOS は操作なしの再生を止めることがある。自動で次の文へ進めなかった場合は
「タップして続ける」が出るので、それを押せば続きから再開する。

## 保存されるもの

- **教材**（動画 ID・教材名・文リスト・苦手マーク・再開位置）→ IndexedDB
- **調べた単語**（単語・回数・出てきた文・教材名・日時）→ IndexedDB
- **練習設定と配色** → localStorage

いずれもブラウザの中だけに残り、外に送られることはない。一覧から教材を削除できる。
プライベートモードなど保存領域が使えない環境では、保存だけが無効になり練習は普通にできる。

### 期限について

アプリ側は**期限を設けていない**。自分で削除しない限り残る。

ただし**ブラウザ側の都合で消えることがある**。Safari は一定期間サイトを開かないと
保存領域を消す（ITP）。これはアプリからは止められないので、次の 2 つで備えている。

- 開いた時点で `navigator.storage.persist()` を呼び、保存領域を消さないよう頼む。
  許可されるかはブラウザ次第（iOS はホーム画面に追加すると通りやすい）
- 一覧の **書き出す** で教材と調べた単語を 1 つの JSON ファイルに保存できる。**読み込む** で戻せる

書き出したファイルは別の端末でも読み込める。PC で取り込んだ教材を iPhone に移すにも使う。
同じ教材が両方にある場合は、更新が新しい方を残すので、進捗が巻き戻らない。
単語も同じく、同じファイルを二度読み込んでも回数は増えない（足さずに多い方を採る）。
単語の無い古い控え（版 1）もそのまま読み込める。

## 見た目

Apple のサイトや iOS の UI に寄せたデザイン言語で組んである。
OS のフォント（`-apple-system` 系）、ピル型のアクションボタン、iOS 風のセグメンテッドコントロールと
スイッチ、角丸 18px のカードと控えめな影。Apple のロゴやフォントファイルなどの素材は含まない。

配色はライトが既定（背景 `#f5f5f7`）。OS がダークならダークで開き、以後も OS の切り替えに追従する。
右上のトグルで手動切り替えもでき、その場合は選択が `localStorage` に保存されて追従をやめる。
ダーク側も純黒は使わず `#1d1d1f` を基調にしている。

## 公開

GitHub Pages への配信は `.github/workflows/pages.yml` が行う。ブランチに push すると
テストとビルドを通し、その成果物 (`dist`) を Pages に渡す。

**Pages の Source は「GitHub Actions」にする**（Settings → Pages → Source）。
「Deploy from a branch」のままだと、GitHub 純正の `pages build and deployment` が
push のたびに走り、リポジトリのルート（ビルド前のソース）をそのまま配信する。
このワークフローはこちらのデプロイより後に終わるので、ビルド成果物を上書きしてしまう。
配信されるのはソースの `index.html` で、`/src/main.tsx` を読もうとして動かない。

この状態で開くと、画面に原因と直し方が出るようにしてある（`index.html` の起動チェック）。

`vite.config.ts` の `base` は `'./'` なので、`https://<user>.github.io/<repo>/` のような
サブパス配信でもアセットの参照は崩れない。

## 開発

```bash
npm run dev      # 開発サーバー
npm test         # テスト（パーサと文分割エンジン）
npm run build    # 本番ビルド
```

```
src/
  lib/
    parseSubtitles.ts    形式を自動判定して cue に正規化
    segment.ts           重複除去と文への結合（分割精度の肝）
    useYouTubePlayer.ts  IFrame Player API での区間再生
    usePractice.ts       聞く / 理解する / 真似る の状態機械
    material.ts          教材の型と純粋な操作（再開位置・苦手マーク・復習の絞り込み）
    edit.ts              文の分割・結合・区間のずらし
    dictionary.ts        語句から調べ先の URL を組み立てる
    difficulty.ts        字幕から教材の手応えを見積もる
    askPrompt.ts         調べた語句を、貼れる質問文にする
    clipboard.ts         クリップボードへの書き込み（退避路つき）
    words.ts             調べた単語の記録・並び替え・突き合わせ
    db.ts                IndexedDB の薄いラッパ
    useLibrary.ts        保存した教材の読み書き
    useWords.ts          調べた単語の読み書き
    backup.ts            書き出しファイルの検証と取り込み時の突き合わせ
    useSettings.ts       練習設定の永続化
    useTheme.ts          配色の切り替えと OS 設定への追従
  components/
    CaptionWords.tsx     字幕から語句を選んで調べる
    DifficultyMeter.tsx  教材の手応えの表示
    ImportPanel.tsx      取り込み画面
    Library.tsx          保存した教材の一覧
    WordList.tsx         調べた単語の一覧
    PracticeView.tsx     練習画面
    SentenceList.tsx     文の一覧
    ThemeToggle.tsx      配色トグル
```

字幕は自分で用意したものを取り込む形にしている。理由と自動取得の選択肢は
[PLAN.md](./PLAN.md#字幕の入手方法をなぜ貼り付けにしたか) にまとめた。
